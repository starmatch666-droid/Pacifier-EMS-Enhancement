# 安抚者与电磁战备

《绝地潜兵 2》Lua 注入型模组。**一个安装 ZIP 内含三个独立组件**，仅需 Bingus Shared Loader（API 1），不需要 HD2 Entity Locator 或其他共享定位器。

## 功能

### AR-32 安抚者

- 穿甲等级改为 **4（重甲穿透）**，四个命中角度全部生效
- 眩晕能力提高（表内眩晕值设为 **5.0**）
- **保留原有基础伤害**
- 目标是更可靠地控制强袭虫；击晕所需命中数仍会受实际命中部位等因素影响

### 轨道电磁冲击波攻击

- 表内原始冷却改为 `30 ÷ 0.95 ≈ **31.58 秒**`
- 战舰升级等游戏内修正可能使面板显示值不同

### A/M-23 电磁冲击波迫击哨戒炮

- 表内原始冷却改为 **90 秒**

### 静电场

- 两条静电场记录（`StaticField55` / `StaticField188`）均由 **15 秒 → 30 秒**
- 由于两条记录都被修改，**除轨道电外，另一种电磁效果（可能包括迫击炮）也可能被延长**

## 已知限制

轨道电的**「落地时间 1.5 秒」未纳入本包**。

测试版虽然成功写入了候选数据字段，但实机中没有产生预期效果；本包**不声称**缩短落地时间。

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。

无需其他前置，下载即用。

## 安装

1. 安装并启用 Bingus Shared Loader（API 1）
2. 在 Arsenal / HD2 Mod Manager 中导入本 ZIP，部署后**完全重启游戏**
3. **不要同时启用**此前的安抚者、电磁战备、静电场**测试包**，以免同一数据记录被重复修改

Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 当前版本：`0.1.0`（实验版）
- 目标游戏构建：**25327279**
- 本包校验 `game.dll` 的 SHA-256：`73374bd4e38386beb9a23bef480082b67d457ebc77485fbec5f488b4e95e201f`，**其他构建会拒绝写入**

三个组件的前一轮测试版均记录了原值校验、写入与回读成功；用户反馈落地时间无效、其他效果初步正常。本发布包移除了落地时间写入，已通过离线 LuaJIT 仿真与拒写变异测试。

**发布包本身尚未重新实机测试**，游戏内效果仍以重新部署后的实测为准。

## 日志

三个组件各有独立日志：

- `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\PacifierHeavyStunLarge5.log`
- `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\EmsStratagemValues.log`
- `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\EmsStaticFieldDuration.log`

写入成功会记录 `applied_template_gameplay_unverified`；数据不匹配时记录 `*_not_write` 并**拒绝写入**，不会强行覆盖。

## 注意

- 内存模组属**客户端运行时改动**：只在本次游戏会话内生效，退出游戏即恢复原状。
- 联机表现可能与队友不一致，并存在**反作弊风险**。建议仅在知情固定队环境中使用。
- 卸载：用管理器禁用本包并重新部署；手动安装需保持 `patch_N` 编号连续，**不要直接删除中间编号的文件**。
